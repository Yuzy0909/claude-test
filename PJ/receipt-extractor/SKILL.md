# 領収書情報抽出スキル

領収書・レシートの画像またはPDFを読み取り、指定された項目を構造化して出力する。

## 抽出する項目

1. **日付** － 領収書に記載された取引日
2. **取引先名** － 発行元の法人名・屋号（例：株式会社〇〇、〇〇チェーン）
3. **店舗名** － 取引先の個別店舗名（例：〇〇店、〇〇支店）。店舗名の記載がない場合は「記載なし」
4. **住所** － 店舗または発行元の住所。記載がない場合は「記載なし」
5. **インボイス登録番号** － 「T」から始まる13桁の番号（例：T1234567890123）。記載がない場合は「未登録業者」と出力する
6. **金額**
   - 税率が単一の場合：税抜金額・消費税額・税込金額
   - 税率が複数（8%・10%混在など）の場合：税率ごとに区分して抽出
7. **備考** － 品目・摘要・内容など備考欄に相当する記載
8. **支払い方法** － 現金・クレジットカード・電子マネー・銀行振込など判別できる形で

## 手順

1. ユーザーから画像またはPDFファイルのパスを受け取る
2. Read ツールでファイルを読み込む（画像・PDFともに対応）
3. 読み取った内容から上記項目を抽出する
4. 下記フォーマットで出力する
5. ユーザーが「CSVに保存して」「スプレッドシートに書き込んで」などを求めた場合、またはデフォルトの保存先が設定されている場合は、`scripts/save_to_csv.py` を使ってCSVに追記する（手順は「CSV保存手順」セクション参照）

## 出力フォーマット

```
## 領収書情報

- 日付　　　　　　　: YYYY年MM月DD日
- 取引先名　　　　　: ○○○○（法人名・屋号）
- 店舗名　　　　　　: ○○店 ／ 記載なし
- 住所　　　　　　　: ○○県○○市○○ ／ 記載なし
- インボイス登録番号: T0000000000000 ／ 未登録業者

### 金額明細

【税率が単一の場合】
- 税抜金額　: ¥X,XXX
- 消費税額　: ¥XXX（XX%）
- 税込金額　: ¥X,XXX

【税率が複数の場合（例：8%と10%が混在）】
- 8% 対象
  - 税抜金額: ¥X,XXX
  - 消費税額: ¥XXX
  - 税込金額: ¥X,XXX
- 10% 対象
  - 税抜金額: ¥X,XXX
  - 消費税額: ¥XXX
  - 税込金額: ¥X,XXX
- 合計税込金額: ¥X,XXX

### その他

- 備考　　　　: （品目・摘要・内容など）
- 支払い方法　: 現金 / クレジットカード（ブランド名）/ 電子マネー（種別）/ 銀行振込 など
```

## CSV保存手順

抽出した情報を `scripts/save_to_csv.py` でCSVファイルに追記する。

**ファイル名：** `日付_取引先名_合計金額.csv`（例：`20260609_セブン-イレブン_671.csv`）で自動生成される。

**デフォルト保存先ディレクトリ：** `~/Documents`（ユーザーが別のディレクトリを指定した場合はそちらを使う）

```bash
python3 scripts/save_to_csv.py \
  --output ~/Documents \
  --date "YYYY年MM月DD日" \
  --supplier "取引先名" \
  --store "店舗名（なければ 記載なし）" \
  --address "住所（なければ 記載なし）" \
  --invoice "T〇〇〇〇〇〇〇〇〇〇〇〇〇（なければ 未登録業者）" \
  --tax8-excl 金額 --tax8-tax 金額 --tax8-incl 金額 \
  --tax10-excl 金額 --tax10-tax 金額 --tax10-incl 金額 \
  --total 合計税込金額 \
  --note "備考テキスト" \
  --payment "支払い方法"
```

- 税率が単一（8%のみ or 10%のみ）の場合、該当しない税率の引数は省略してよい（空文字で記録される）
- CSVが存在しない場合はヘッダー行を自動作成してから追記する
- 文字コードは UTF-8（BOM付き）で保存するため Excel で直接開ける

## 読み取れない・不明な項目の扱い

- 記載がない・判読できない項目は `記載なし` と出力する
- 金額の内訳（税抜・消費税）が明示されておらず税込金額のみの場合は、その旨を記載する
- 税率の区分が不明な場合は「税率不明」として税込合計のみ出力する

## 注意事項

- 画像が傾いていたり、一部が欠けていても読み取れる範囲で最大限抽出する
- 複数枚の領収書が1ファイルに含まれる場合は、領収書ごとに区切って出力する
- ユーザーが「CSV形式で出力して」など形式を指定した場合はそれに従う
