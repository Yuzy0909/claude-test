## web-reference-finder スキル

執筆済み記事のテーマ・キーワードをもとにWebサーチを行い、類似するブログ・記事を見つけてタイトルを参考文献として表示します。

### 手順

1. **検索クエリの生成**
   - 記事のメインキーワードと関連キーワードを組み合わせて検索クエリを3〜5個作成する
   - 日本語クエリと英語クエリを混在させてもよい

2. **WebSearchツールで検索**
   - 各クエリで `WebSearch` ツールを実行する
   - 検索結果からタイトル・URLを収集する

3. **結果のフィルタリング**
   - 記事のテーマと明らかに無関係な結果を除外する
   - 公式ドキュメント・Wikipedia・ニュースサイトは除外せず含める
   - 重複するドメインは代表1件に絞る

4. **参考文献の出力**
   - タイトルを `##` 見出し形式で表示する
   - URLをMarkdownリンクとして付与する
   - 5〜10件を目安に出力する

### 出力形式

```markdown
---

## 参考文献

## [記事タイトル1](URL1)
## [記事タイトル2](URL2)
## [記事タイトル3](URL3)
...
```

### 注意事項

- WebSearchツールが利用できない場合はその旨を伝え、スキルを終了する
- URLが取得できない場合はタイトルのみ（リンクなし）で出力する
- 検索結果が少ない場合は検索クエリを変えて再検索する
