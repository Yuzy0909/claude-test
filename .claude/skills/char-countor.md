## char-countor スキル

テキストの文字数を以下の4パターンで計測します。

### 計測パターン

| パターン | 改行 | スペース（全角・半角・タブ） |
|:---:|:---:|:---:|
| A | 含む | 含む |
| B | 含む | 含まない |
| C | 含まない | 含む |
| D | 含まない | 含まない |

### 計測手順

Bashツールを使って以下のコマンドで計測します。
`TEXT` 変数に計測対象テキストをセットして実行してください。

```bash
# 計測対象テキストをファイルに保存（フロントマターは除外）
TEXT=$(cat article.md | sed '/^---$/,/^---$/d')

# パターンA: 改行含む・スペース含む（生の文字数）
COUNT_A=$(echo "$TEXT" | wc -m | tr -d ' ')

# パターンB: 改行含む・スペース含まない（全角スペース・半角スペース・タブを除去）
COUNT_B=$(echo "$TEXT" | tr -d ' \t　' | wc -m | tr -d ' ')

# パターンC: 改行含まない・スペース含む（改行のみ除去）
COUNT_C=$(echo "$TEXT" | tr -d '\n' | wc -m | tr -d ' ')

# パターンD: 改行含まない・スペース含まない（改行・全角スペース・半角スペース・タブを除去）
COUNT_D=$(echo "$TEXT" | tr -d '\n \t　' | wc -m | tr -d ' ')

echo "A（改行含む・スペース含む）:    $COUNT_A 字"
echo "B（改行含む・スペース含まない）: $COUNT_B 字"
echo "C（改行含まない・スペース含む）: $COUNT_C 字"
echo "D（改行含まない・スペース含まない）: $COUNT_D 字"
```

### 出力形式

```
【文字数カウント結果】
────────────────────────────────
  A. 改行含む   ／ スペース含む   : X,XXX 字
  B. 改行含む   ／ スペース含まない: X,XXX 字
  C. 改行含まない／ スペース含む   : X,XXX 字
  D. 改行含まない／ スペース含まない: X,XXX 字
────────────────────────────────
※ スペース対象: 半角スペース・全角スペース（　）・タブ

【目標比較】（目標文字数が指定されている場合）
- 目標文字数 : X,XXX 字
- 比較基準   : パターンD（実質文字数）
- 差分       : +XXX 字 ／ 目標比 XXX%
- 判定       : ✅ 目標範囲内（±5%） ／ ⚠️ 拡張が必要 ／ ⚠️ 圧縮が必要
```

### 目標文字数との比較基準

記事の文字数最適化では **パターンD（改行含まない・スペース含まない）** を基準として目標文字数と比較します。
これが読者が実際に読む「純粋な文字数」に最も近いためです。

### 使用タイミング

1. 初稿完成後に必ず計測する
2. 拡張・圧縮後に再計測して目標範囲内か確認する
3. 最終出力前に最終確認として計測する
