# upstream差分の確認

配布元リポジトリ（`upstream`）に新しい更新がないかを確認し、何が変わったかを人が読める形でまとめて報告する。
**このスキルは確認と報告だけを行う。ファイルの上書き・取り込みは、人が内容を見て指示してから別途行う。**

## 手順

### 1. upstreamの最新を取得

```bash
git fetch upstream
```

`upstream`リモートが登録されていない場合は、先に登録を案内する：

```bash
git remote add upstream <配布元のURL>
git remote set-url --push upstream no_push
```

### 2. 新規コミットの一覧を表示

```bash
git log main..upstream/main --oneline
```

コミットが無ければ「upstreamに新しい更新はありません」と報告してスキルを終了する。

### 3. 変更ファイルの一覧を表示

```bash
git diff --stat main upstream/main
```

### 4. カスタマイズ済みファイルへの警告

変更ファイル一覧に、以下のいずれかが含まれていないか確認する。含まれていたら、
「⚠️ カスタマイズ済みファイルです。upstream側の内容でそのまま上書きすると、これまでの設定が失われます」
と明記して一覧に警告マークを付ける。

- `CLAUDE.md`
- `.claude/rules/persona.md`
- `.claude/rules/context7.md`
- `.claude/settings.json`
- `勘定科目ルール.md`
- `.claude/memory/` 配下のファイル

### 5. 結果をまとめて報告

次の形式で報告する。

```
## upstream差分レポート

新規コミット: N件
- <コミットメッセージ>（<日付>）
...

変更ファイル一覧:
- <ファイルパス>（+追加行数 / -削除行数）  ← カスタマイズ済みなら ⚠️ 付き
...
```

### 6. 取り込みの判断は人に委ねる

報告後、「どのファイルを取り込みますか？」と確認する。
- カスタマイズ済みでないファイル（新規スキル・新規教材フォルダなど）は基本そのまま取り込んでよい
- カスタマイズ済みファイルは、差分の中身を個別に見せてから、取り込むかどうかを1件ずつ確認する

承認された分だけ `git diff main upstream/main -- <ファイルパス>` で中身を確認し、該当ファイルを反映してコミットする。
